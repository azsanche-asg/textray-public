# Screenshots

Screenshots in this folder are for portfolio display only. They must be captured from the running macOS TextRay app using neutral demo content.

## Capture Rules

- Use the macOS app, not an iOS Simulator.
- Use neutral demo notes only.
- Do not show real user notes, drafts, snippets, credentials, private paths, local usernames, signing identities, certificates, or internal development notes.
- Do not show old notes named like internal batch work.
- Do not show visuals that imply public release, notarization, stapling, or App Store readiness before those states are complete.
- Save images as PNG.

## Missing Screenshot Policy

If a screenshot is absent, it means it could not be captured safely and reliably without risking user data exposure or misleading release-status visuals. Retake missing screenshots manually from a clean demo state before publishing the mirror.

## Captured Screenshot Notes

All app UI screenshots were captured from the running macOS TextRay app using neutral demo content prepared for screenshots. The session used titles and terms such as Conference Notes, Launch Checklist, Search Examples, Writing Draft, Privacy Notes, and Project Alpha.

`onboarding.png` shows the first-run onboarding sheet with the local-first and deterministic-search explanation.
