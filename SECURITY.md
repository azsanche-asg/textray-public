# Reporting a security concern

Please report suspected vulnerabilities privately to [hello@burritoslabs.com](mailto:hello@burritoslabs.com), with “TextRay security” in the subject.

Include the affected version, platform, expected impact and a minimal reproduction using fictional data. Do not open a public issue with exploit details, private text, activation codes or credentials. We may ask for a smaller reproduction or agree on a way to exchange additional material.

This is a contact route, not a bug-bounty offer or a guarantee of a response deadline. Current compatibility and qualification scope are listed in [distribution](docs/PACKAGING_AND_DISTRIBUTION.md).
